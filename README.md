# Human–Computer Interaction Lab — University of Winnipeg

Responsive static HTML/CSS/JavaScript implementation of the Figma frame [Human-Computer Interaction Lab](https://www.figma.com/design/Qy6nSweDfeEARJF8BJQ2B5/UW-Figma-Session?node-id=515-1316). No build step or package dependencies are required.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Deploy on GitHub Pages

The included workflow at `.github/workflows/pages.yml` deploys the repository root on pushes to `main`. In repository Settings → Pages, select **GitHub Actions** as the build and deployment source if it is not already selected.

## Before official use

The research descriptions, thematic illustrations, and contact destination are starter content. Confirm lab research, personnel, publications, contact information, and University of Winnipeg approval before representing this as an official university lab website.
